# Sample Manuals

Place your appliance PDF manuals in this directory for testing.

You do **not** need to commit real PDF files to GitHub.

## Where to find sample PDFs

Several appliance manufacturers publish their manuals publicly:

| Brand | URL |
|---|---|
| Samsung | https://www.samsung.com/us/support/manuals/ |
| LG | https://www.lg.com/us/support/manuals-documents |
| Whirlpool | https://www.whirlpool.com/content/dam/documents/manuals/ |
| Bosch | https://www.bosch-home.com/us/service/service-and-support/manuals/ |

Download any PDF manual from these sources and upload it through the app.

## Note on scanned PDFs

ApplianceAssist AI requires PDFs with **selectable (digital) text**.  
Scanned-image PDFs (photographed pages) will not produce extractable text  
and will show a warning in the application.

## Example test questions (once a manual is loaded)

1. "What does error code E3 mean?"  
2. "How do I activate the eco mode?"  
3. "What is the recommended filter cleaning interval?"  
4. "What safety precautions should I follow before servicing the appliance?"  
5. "How do I reset the appliance to factory defaults?"
